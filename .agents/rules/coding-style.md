# Coding Style & Design Rules

## Functional & Arrow Functions
- Prefer functional programming and pure functions over classes across all services, calculations, database modules, and utilities.
- Do not use classes unless strictly required by external libraries or framework conventions.
- Prefer arrow functions for all functions, components, hooks, and helpers.

## Clean Code
- Always apply the `clean-code` skill principles:
  - Keep functions concise, focused, and single-purpose.
  - Maintain high readability and self-documenting code with meaningful names.
  - Ensure domain calculations remain pure, predictable, and fully unit tested.
