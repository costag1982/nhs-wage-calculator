Flow 1: User Adds / Edits a Shift on Mobile or Laptop
Write Flow
Step 1 ✍️
User Enters Shift
Gemma taps a date on the calendar, selects Night Shift (20:00–06:00), and taps "Save Shift".
Step 2 ⚡
Section 2 Wage Recalc
Calculates Saturday (41%), Sunday (83%), Night enhancements, PAYE, and pension in <1ms.
Step 3 💾
SQLite & IndexedDB Save
Commits SQL row: INSERT INTO shifts and writes binary snapshot to IndexedDB.
Step 4 ⏱️
Debounced Auto-Sync
Sets lastModified timestamp and waits 1.5s to batch any rapid subsequent edits.
Step 5 ☁️
Gist Patch Upload
Sends PATCH /gists/:id to GitHub. Header badge updates to 🟢 Cloud Synced.
2
Flow 2: Gemma Opens App on Another Device (iPad / Mac)
Read & Merge Flow
Step 1 🔑
App Passphrase Unlock
Gemma enters passphrase on new device. Web Crypto API decrypts React application in memory.
Step 2 🔍
Cloud Sync Check
CloudSyncService queries GitHub Gist for latest lastModified timestamp.
Step 3 📥
Remote Newer Detected
Remote timestamp is newer than empty/local database. Downloads full JSON payload.
Step 4 🔄
SQLite DB Hydration
Replaces local tables with remote shifts, employee profile, and recurring deductions.
Step 5 ✨
UI Instantly Refreshes
Calendar, shifts list, and digital ESR payslip render with all synced shifts immediately.
3
Flow 3: Offline Usage (In Hospital Ward / No Signal)
Offline Resilience Flow
Step 1 📡❌
No Internet Detected
Gemma works in hospital with no Wi-Fi. Browser detects navigator.onLine = false.
Step 2 ⚡
100% Offline Functionality
Full calculator, roster, and salary forecasts continue running locally in SQLite with zero lag.
Step 3 ⚪
Offline Mode Badge
Header badge displays ⚪ Offline Mode (Saved locally) so Gemma knows data is safe.
Step 4 📶
Signal Restored
Device reconnects to 4G/Wi-Fi. window.online and visibility events fire automatically.
Step 5 ☁️✅
Automatic Background Sync
Sync engine pushes pending local mutations to GitHub Gist. Status returns to 🟢 Cloud Synced.

Flow 4: Manual .sqlite File Export & Import
File Backup Flow
Export 📤
Export .sqlite File
Tapping "Export .sqlite DB" in Settings exports the raw binary database to nhs_roster_database.sqlite.
Import 📥
Import .sqlite File
Selecting any previous .sqlite backup file rehydrates the database and IndexedDB immediately.
Cloud Update ☁️
Auto Cloud Upload
Importing a file triggers scheduleAutoSync(), immediately updating the Cloud Gist with the restored data.
