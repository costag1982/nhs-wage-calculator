Flow 1: User Adds / Edits a Shift or Changes Settings

Step-by-step transaction lifecycle from user click to cloud confirmation

Write & Sync Flow
Step 1 • Input
✍️ User Action
Gemma taps a calendar date, selects shift preset (e.g. Night 20:00–06:00), and saves.
addShift(shiftData)
Step 2 • Calc
⚡ Section 2 Recalc
WageCalculator recalculates unsocial enhancements, pension, and PAYE tax instantly.
calculateMonthlyPayslip()
Step 3 • Local Save
💾 SQLite Commit
Commits SQL row into in-memory database and writes binary snapshot to IndexedDB.
SqliteStorage.saveShift()
Step 4 • Debounce
⏱️ Auto-Sync Queue
Records local mutation timestamp and queues a 1.5s debounced sync payload.
scheduleAutoSync(1500ms)
Step 5 • Cloud
☁️ Gist Synced
Sends PATCH request to private GitHub Gist. Header badge turns to 🟢 Cloud Synced.
PATCH /gists/:gist_id
